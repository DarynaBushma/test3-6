### 1. Арифметична операція: $X1 + X2$
Виконуємо додавання в регістрах:
```text
  00010000 (X1 = 16)
+ 01101010 (X2 = 106)
----------
  01111010 (Результат = 122)
```
У десятковій системі: $16 + 106 = 122$.

**Формування ознак (Flags) після додавання:**
* **ZF = 0**: результат не дорівнює нулю;
* **SF = 0**: знаковий біт результату — 0 (число додатне);
* **OF (V) = 0**: переповнення відсутнє, оскільки сума (122) входить у діапазон допустимих значень для 8-бітових чисел зі знаком (від -128 до 127);
* **CF (C) = 0**: переносу за межі 8-го розряду немає.

**Висновок щодо нормалізації:** Оскільки ознака переповнення $OF = 0$, результат операції є достовірним і не потребує додаткової нормалізації (корекції розрядної сітки).

### 2. Логічний зсув: $2 \times X2$

* $X2$ = `01101010` (106)
* $2 \times X2$ = `11010100` (212 як unsigned еквівалент)

### 3. Логічна операція: $F = (X1 + X2) \ \& \ 2X2$
Виконуємо порозрядне логічне "І" (AND) між результатом додавання та результатом зсуву:

AND 11010100 (212)
------------

**Перевірка в десятковому коді:**

$(122) \text{ AND } (212) = 80$. Розрахунки вірні.

**Аналіз ознаки результату:**
Фінальний результат $F \neq 0$, отже ознака рівності нулю **ZF = 0**.
