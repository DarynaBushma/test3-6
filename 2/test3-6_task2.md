## Виконання завдання

### 1. Переведення номера в двійкову систему

Номер залікової книжки: $4202_{10}$

$$4202 = 2^{12} + 2^6 + 2^5 + 2^3 + 2^1 = 4096 + 64 + 32 + 8 + 2$$

Двійкове представлення (16 розрядів):
**0001 0000 0110 1010**

Визначаємо молодші розряди для вибору функції:
$h_1 = 0$, $h_2 = 1 \Rightarrow h_1h_2 = 01$

Згідно з таблицею варіантів, для комбінації **01** функція має вигляд:
$$F = (X1 + X2) \ \& \ 2X2$$

### 2. Формування аргументів

Розділяємо 16-бітне число на два 8-бітних регістри:
* **X1 (R1):** $00010000_2 = 16_{10}$
* **X2 (R2):** $01101010_2 = 106_{10}$

Обидва числа мають знаковий розряд (MSB) рівний `0`, що означає додатні числа.

### 3. Покрокове обчислення

#### Крок 1: Додавання $A = X1 + X2$
$$00010000 (16) + 01101010 (106) = 01111010 (122)$$
**Ознаки:**
* **C (Carry):** 0 (переносу немає)
* **V (Overflow):** 0 (результат в межах [-128, 127])
* **S (Sign):** 0 (число додатне)
* **Z (Zero):** 0 (результат не нуль)

#### Крок 2: Логічний зсув $B = 2 \times X2$
Виконуємо арифметичний зсув вліво на 1 розряд для $X2$:
$$01101010 \ll 1 = 11010100 (212_{10} \text{ як unsigned})$$

#### Крок 3: Логічна операція $F = A \ \& \ B$
Виконуємо порозрядне "І" (AND):
$$01111010 \ \& \ 11010100 = 01010000$$

## Цифрова діаграма стану регістрів

| Операція | Бінарне значення | Десяткове значення | C | V | S | Z |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **X1** | `0001 0000` | 16 | - | - | - | - |
| **X2** | `0110 1010` | 106 | - | - | - | - |
| **X1 + X2** | `0111 1010` | 122 | 0 | 0 | 0 | 0 |
| **2 * X2** | `1101 0100` | - | - | - | - | - |
| **Результат F** | `0101 0000` | 80 | - | - | 0 | 0 |

## Аналіз результатів

1. **Ознака нормалізації:** При додаванні $X1 + X2$ прапорець переповнення $V=0$. Це означає, що результат операції коректно розмістився у 8-бітній сітці, і проблема нормалізації (корекції переповнення) для даного набору даних не виникла.
2. **Ознака рівності нулю:** Фінальний результат $F = 01010000_2$ не є нульовим, тому прапорець $Z = 0$.
3. **Перевірка:**
   - Сума: $16 + 106 = 122_{10}$
   - Зсув: $106 \times 2 = 212_{10}$
   - Логічне І: $122 \ \& \ 212 = 80_{10}$
   - Бінарний результат `0101 0000` відповідає $2^6 + 2^4 = 64 + 16 = 80$. Обчислення вірні.
