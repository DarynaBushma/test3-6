## 1. Переведення номера в двійкову систему

Номер залікової книжки: $4202_{10}$

$$4202_{10} = 1000001101010_{2}$$

Доповнюємо до 16 розрядів ($h_{16} \dots h_1$):
$$0001 \ 0000 \ 0110 \ 1010_2$$

Визначаємо значення для вибору функції за розрядами $h_1, h_2$:
$$h_1 = 0, \ h_2 = 1 \Rightarrow h_1h_2 = 01$$

Для комбінації $01$ функція має вигляд:
$$F = (X1 + X2) \text{ \& } 2X2$$

## 2. Формування аргументів R1 та R2

Розділяємо отримане 16-розрядне число на дві мантиси зі знаками (8 розрядів кожна):

$$X1 = h_{16} \dots h_9 = 00010000_2 = 16_{10}$$
$$X2 = h_8 \dots h_1 = 01101010_2 = 106_{10}$$

Старші розряди в обох аргументах рівні $0$, що свідчить про додатні значення чисел.

## 3. Виконання функції та діаграма станів

Обчислення проводиться у три етапи: додавання, логічний зсув (множення на 2) та порозрядна операція "І".

### Цифрова діаграма стану регістрів

| Операція | Регістр | Значення у двійковій системі | Значення у десятковій системі | Ознаки (Z, S, V, C) |
| :--- | :--- | :--- | :--- | :--- |
| Аргумент 1 | $X1$ | $00010000$ | $16$ | - |
| Аргумент 2 | $X2$ | $01101010$ | $106$ | - |
| **Додавання** | $A = X1 + X2$ | $01111010$ | $122$ | $Z=0, S=0, V=0, C=0$ |
| **Зсув (2X2)** | $B = X2 \ll 1$ | $11010100$ | $212$ | - |
| **Результат** | $F = A \text{ \& } B$ | $01010000$ | $80$ | **$Z=0$** |

## 4. Аналіз результатів та перевірка

### Пояснення ознак та нормалізації:
1. **Арифметична операція ($X1 + X2$):** Сума чисел $16$ та $106$ дорівнює $122$. Оскільки результат не перевищує максимально можливе значення для 8-бітного регістра зі знаком ($+127$), ознака переповнення $V = 0$. Результат є нормалізованим і не потребує корекції.
2. **Логічна операція:** Виконано порозрядне кон'юнкцію результатів перших двох етапів.
3. **Ознака рівності нулю:** Кінцевий результат обчислення функції $F = 01010000_2$ ($80_{10}$). Оскільки результат не є нульовим, прапорець ознаки нуля $Z = 0$.

### Перевірка в десятковому коді:
$$F = (16 + 106) \text{ \& } (106 \times 2) = 122 \text{ \& } 212$$

Переведемо числа в двійкову систему для перевірки логічного "І":
$$122_{10} = 01111010_2$$
$$212_{10} = 11010100_2$$

$$01111010 \text{ AND } 11010100 = 01010000_2 = 80_{10}$$

**Висновок:** Результати обчислень у двійковій та десятковій системах збігаються, що підтверджує правильність виконання завдання.
